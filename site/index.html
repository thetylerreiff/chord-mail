Mail at the speed of a keypress

A Gmail client for Omarchy that lives on your keyboard. The window reads only from a local cache, so it never waits on the network, and Gmail catches up in the background.

+---------+---------------------------------------+
| TRIAGE  | e done · h snooze · # trash · z undo  |
| CACHE   | SQLite on your machine, works offline |
| COMPOSE | Neovim in a floating terminal         |
| THEME   | follows your Omarchy theme, live      |
| PRIVACY | your own OAuth client, no middleman   |
| CLI     | --json for scripts and agents         |
+---------+---------------------------------------+

Install

$ curl -fsSL https://chord.thetylerreiff.co/install | bash

Builds the Arch package from source, so Chord lands in your launcher with its background service. Arch or Omarchy, x86_64 or aarch64. Copy it with c. [ Read the script ]
