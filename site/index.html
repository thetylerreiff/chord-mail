CHORD 0.1.0 GitHub ↗ Connect Gmail ↗

Mail at the speed of a keypress.

A Gmail client for Omarchy that lives on your keyboard. It reads only from a local cache, so it never waits on the network.

  • Cache SQLite, local, offline
  • Compose Neovim
  • Theme follows Omarchy
  • Sign-in your own OAuth client
  • CLI --json
  • License MIT
